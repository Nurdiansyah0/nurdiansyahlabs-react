## 📈 BONUS: How to Track These Keywords

1. **Google Search Console** (free) — already verified on your site  
   → Go to Performance → Queries to see what's already bringing traffic

2. **Google Keyword Planner** (free with Google Ads account)  
   → Search each keyword above to validate monthly volume in Indonesia

3. **Ubersuggest** (free tier) → ubersuggest.com  
   → Enter each keyword, select Indonesia as country

4. **Check competition** by Googling each keyword in incognito mode  
   → If results are dominated by Shopify/Tokopedia/big agencies = harder  
   → If results show freelancer blogs or small sites = easy to rank!
