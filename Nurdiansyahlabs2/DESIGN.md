# Elite Digital Tech Solutions Design System

This design system defines the visual language for the Elite Digital Tech Solutions brand, optimized for a premium, tech-forward aesthetic.

## 🎨 Color Palette

### Primary (Electric Indigo)
- **Base**: `#6366f1`
- **Gradient**: `linear-gradient(135deg, #6366f1 0%, #a855f7 100%)`
- **Glow**: `0 0 20px rgba(99, 102, 241, 0.4)`

### Secondary (Cyber Cyan)
- **Base**: `#06b6d4`
- **Accent**: `#22d3ee`

### Surface (Obsidian)
- **Background**: `#0a0a0b`
- **Card**: `rgba(255, 255, 255, 0.03)`
- **Border**: `rgba(255, 255, 255, 0.08)`

## typography

- **Font Family**: 'Inter', sans-serif (Google Fonts)
- **Headings**: 'Outfit', sans-serif
- **Scale**:
  - H1: 4rem / 700 weight
  - H2: 2.5rem / 600 weight
  - Body: 1.125rem / 400 weight

## ✨ Effects

- **Glassmorphism**: `backdrop-filter: blur(12px); border: 1px solid rgba(255, 255, 255, 0.1);`
- **Roundness**: `16px` (Default for cards and buttons)
- **Animation**: Cubic-bezier transitions for smooth micro-interactions.
